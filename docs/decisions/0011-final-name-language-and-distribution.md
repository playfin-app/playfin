# 0011 — Final name, identifier, language and distribution

Date: 2026-10-09. Decisions delegated by the human ("make the decisions you want").

- **Name**: Playfin. **Identifier**: `com.playfin.app` (used by the app folders and the Keychain: changing it would make users lose their data). The README says "a client for Jellyfin" and the app does not use the Jellyfin logo; the icon is drawn by `scripts/make-icon.swift`.
- **Version**: 0.11.0 (`MARKETING_VERSION`; 0.9.0 was the first public pre-release); 1.0.0 comes once the remaining changes are in, overridden by the tag in the release workflow.
- **Interface language**: English. Texts are literal `Text("…")` values, so they are ready for a string catalogue if other languages are added.
- **Distribution**: GitHub Releases + a Homebrew tap `playfin-app/tap` (cask generated by `scripts/update-cask.sh` from `packaging/homebrew/playfin.rb.template`). The `.github/workflows/release.yml` workflow is ready but **nothing has been published**: the human pushes the tag when they decide to, and adds the `HOMEBREW_TAP_TOKEN` secret.
- **Signing**: ad hoc as long as there is no Apple Developer account. `package-release.sh` already accepts `SIGN_IDENTITY` (Developer ID, hardened runtime) and `NOTARY_PROFILE` (notarisation + stapling): nothing to restructure when the time comes.
- **Minimum macOS**: 14 (project default).
